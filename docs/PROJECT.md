## Модель продукта

- **Бесплатно**: 1 простой код (после входа). Предпросмотр любого кода — свободный, платят за скачивание.
- **Платно**: следующие простые (предлагали $1), красивые (своё оформление, $3–9), дизайны из маркета (цена дизайнера),
  тиражи с номерами (дороже), заказ под бренд (пакеты ~$49 и ~$199+).
- **Лозунг**: «купил один раз — работает всегда» (разовая оплата за код, без подписки — главная боль рынка).
- **Кабинет**: 1 страничка под кодом бесплатно; больше фото, видео, страничек — платно (хранение стоит денег).
- **Оплата по миру**: через посредника (Paddle или Lemon Squeezy) — Stripe с армянской компанией напрямую не работает.
  Аккаунт заводит владелец.
- Не утверждено владельцем: точные цены; какие стили простые (предлагали: цвета, квадраты/мягкие/круги, логотип — простые;
  фото, коллаж, текстуры, объём, «Узор», «Микросхема», значок в углах, «Космос» — платные).

## Видение и хайп (предложено, владелец согласен с направлением)

- **Дроп дня** от дизайнера; **тиражи с номерами** («Космос № 37 из 100»), закончился — не купить.
- **Перепродажа** коллекционных кодов между людьми, наш % (это ожившая идея 10 «Миллион номеров»).
- **Скан = реклама**: на страничке после скана «Сделано в … → сделай свой».
- **Живые (анимированные) QR** для Instagram и TikTok, кнопка «поделиться».
- **Коллаборации** «Мы × Бренд»: общая коллекция, тираж, доход пополам; по договору логотип бренда — законно.
  Для звёзд: личный код малым тиражом, № 1 на аукционе, сертификат подлинности (владелец и номер).
  Путь: местные бренды и армянские блогеры → регион → мир. Плюс маркет для художников за процент.
- **Товары** через печать по требованию (вроде Printful), без склада; потом брелоки с NFC; наклейки на машину,
  бирки питомцев, свадебные коды.
- ⭐ **ВАЖНО (владелец, 04.10.2026)** — **QR на машине с номером «по выключателю»**: номер видят, только когда владелец
  включил. Код ведёт на нашу страничку (меняющийся код, нужен сервер). Предложено: номер вообще не показывать —
  «Позвонить / Написать владельцу» через нас (сообщение в Telegram/WhatsApp/SMS, как в такси); готовые кнопки
  («перекрыли выезд», «открыто окно», «горят фары», «эвакуируют»); расписание; защита от спама (лимит, блокировка).
  Это общая функция меток «показывать / скрывать» и «связаться через нас»: дверь (курьер), велосипед, ключи,
  ошейник питомца, чемодан.
- **Брелок «верните находку»** (владелец, 04.10.2026): ключи и вещи. Безопасность — главное: нашедший не узнаёт о владельце
  ничего (имя, адрес, телефон). В коде только случайный номер (не по порядку); после скана — нейтральное «Вы нашли чью-то
  вещь»; связь через нас (анонимный чат → владельцу в Telegram/WhatsApp); вернуть — в людном месте или пункт возврата,
  никогда домой; режим «Потеряно» (пока не включён — скан ничего не показывает; можно вознаграждение через нас);
  уведомление о скане (район — с согласия нашедшего); лимиты и блокировка, никакого списка меток владельца.
  Также: рюкзак, чемодан, ноутбук, чехол телефона, ошейник, детская куртка, велосипед. Та же система, что метка на машине.
- **Питомцы: жетоны и фирменные ошейники** (владелец, 04.10.2026). Анкета питомца открыта (фото, кличка, характер,
  здоровье, номер чипа), хозяин скрыт — связь через нас; режим «Я потерялся!» (+ вознаграждение); уведомление «где
  отсканировали» (с согласия нашедшего). Каждый день: напоминания (прививки, обработка), медкарта для ветеринара,
  инструкции для няни/выгульщика. Жетон маленький (2–3 см) → короткая ссылка (вроде `qrv.io/k7Xq9`), простой крупный
  код, красота — в цвете, форме и узоре вокруг; металл с гравировкой / силикон / эпоксидка. Партнёры: ветклиники,
  зоомагазины, приюты (анкета «возьми меня домой»). Конкуренты есть (PetHub и др.) — проверить. Та же система меток.
- «Знак подлинности»: проверка, что код настоящий (против поддельных наклеек) — в плане, не сделан.

## Аукционы, защита от подделок, ИИ (обсуждение 04.10.2026)

- **Аукционы без крипты**: ставки в долларах, реестр владельцев — у нас (блокчейн — потом, ради престижа, по желанию).
- **Выплаты продавцам** — нерешённая проблема: Paddle и Lemon Squeezy не платят продавцам, Stripe Connect с армянской
  компанией не работает. Варианты: внутренний баланс + вывод через Payoneer/PayPal; компания через Stripe Atlas (США).
  Для площадки с выплатами обычно нужна проверка личности продавцов. Решить до перепродажи.
- **Против подделок** (QR легко скопировать фотографией бирки!): свой код на каждую вещь; скрытый код под стираемым
  слоем — только купивший регистрирует вещь на себя; скан показывает владельца и дату, «уже принадлежит другому» на новой
  вещи = подделка/копия; тревога, если код сканируют в разных городах; для дорогих брендов — NFC-чип с шифрованием
  (NTAG 424 DNA), его не скопировать. Сильное B2B-направление: бренды платят за защиту.
- **ИИ рисует не код, а картинку для кода**: фон, узор, иллюстрацию → наш генератор собирает код (как QR-картинку) и
  проверяет чтение. ИИ, рисующий сам код, почти всегда его ломает.
- **Фирменный стиль** — отдельное обсуждение: 3–5 фирменных коллекций + общий узнаваемый знак на каждом нашем коде.
- **Футболки**: печать по требованию, код из дропа тиражом с номером, ведёт на страничку владельца или коллекции.

## Одна платформа «умных меток» — кирпичики и шаблоны (04.10.2026)

Владелец: «где можно использовать — реально очень много». Все применения (машина, ключи, питомец, котёл, деревья…) —
одна система из 5 кирпичиков:
1. **Страничка**: текст, фото, видео, шаги.
2. **Кто видит**: все / только я / семья; режимы «включено / выключено / потеряно».
3. **Связь через нас**: анонимно, без телефона и адреса.
4. **Напоминания и история**: что и когда сделать, что уже сделано.
5. **Владелец и подлинность**: чья вещь, оригинал ли.

Каждая сфера — **шаблон** с готовыми полями и настройками (не отдельная разработка). Шаблоны, названные владельцем:
Котёл / инструкция, Сад / деревья, Машина (номер по выключателю), Ключи / вещи («верните находку»), Питомец, Вещь бренда
(подлинность). Предложенные: Квартира для гостей (Airbnb), Оборудование офиса/кафе, Свадьба, Детская куртка, Чемодан.
Новые сферы — дописывать сюда списком.

## Память под кодом и приложение — «кто видит» (05.10.2026)

Владелец: у каждого пользователя в профиле под каждым своим кодом — **место памяти** (фото, видео, текст). Все коды
должны открываться **через наше приложение**, чтобы владелец мог выбрать, например, «видят только мои контакты».

Как сделать, чтобы работало у всех (мой совет, владелец не решал):
- **Одна ссылка в коде** (например `qrvivid.com/c/123`). Приложение установлено → ссылка сразу открывает приложение
  (Universal Links / App Links). Не установлено → открывается наша веб-страница, никто не застревает.
- **Открытые коды** (котёл для гостей, Wi-Fi, «верните находку», питомец) — видны всем сразу, без приложения:
  нашедший ключи не будет ставить приложение, и вещь не вернётся.
- **Закрытые коды** («только мои контакты», «только я», «семья») — на веб-странице «Этот код закрыт → откройте в
  приложении / войдите». Так приложение ставят те, кому оно реально нужно — это и есть рост.
- Уровни «кто видит»: все / по запросу (владелец одобряет) / мои контакты / семья / только я; можно по частям
  (фото — всем, телефон — только контактам). Это расширение кирпичика 2 «Кто видит».
- **«Мои контакты»** — 2 способа: друзья внутри нашего приложения (просто, без риска) и сверка с телефонной книгой
  (как WhatsApp/Telegram: только с согласия, номера — в виде хешей, книгу не храним; в Европе строгие правила — GDPR,
  App Store и Google Play требуют объяснить зачем). Начинать с друзей в приложении.
- **Решение владельца (05.10.2026): под кодом можно поставить конкретных людей, для кого он открыт** — «это будет нужно
  очень многим». Как предлагаю: добавить по номеру, имени в приложении или ссылкой-приглашением; права «смотреть» или
  «смотреть и дописывать» (мастер у котла, няня, семья); доступ на время (гость Airbnb — до выезда); убрать человека
  в один нажим; группы («Семья», «Мастера») — добавил раз, используешь для многих кодов.
- Каждое открытие закрытого кода — в историю («кто смотрел»), владелец видит.
- Приложения iOS/Android — позже; первая версия может работать на сайте со входом по номеру/почте.

## Чек-ин через код (идея владельца, 05.10.2026)

Владелец: «через это можно сделать check-in?» Да — это продолжение кирпичиков «Кто видит» (список людей) и «История».
- **Код на месте, человек сканирует**: сотрудник пришёл/ушёл, охранник обошёл точки, уборщица убрала туалет (лист
  на двери → в телефоне), мастер был у котла, ученик на занятии. Отметка: кто, когда, где.
- **Код у человека, его сканируют на входе**: билет на событие, абонемент в спортзал, гость на свадьбе, пропуск.
- **Против обмана** (фото кода и скан из дома): проверка места по геолокации; меняющийся код на экране планшета у
  входа (обновляется каждые 30 с); NFC-метка вместо наклейки; по желанию — селфи при отметке.
- **Владелец (05.10.2026): важно, чтобы не сфотографировали все коды и не отмечались, сидя на одном месте; геолокация
  на складе не поможет — по метрам не определит.** Верно: GPS в помещении ошибается на 10–50 м. Простой QR от фото
  не защитить ничем. Решение (мой совет): **наклейка QR + NFC-чип внутри** (NTAG 424 DNA — при каждом касании чип
  выдаёт новую подпись, её нельзя сфотографировать или скопировать; телефон надо приложить на 2–4 см; читают iPhone и
  Android без приложения; ~$0.5–1.5 за чип). Для зала/проходной — меняющийся код на планшете; для точного «рядом»
  без касания — Bluetooth-маячки (~$10–20, батарейка годами, нужно приложение). Дополнительно — подозрительные отметки
  (10 точек за 30 секунд) помечать владельцу. QR без чипа — только для случаев, где обман не страшен.
- **Владелец (05.10.2026): «QR + чип — что-то бессмысленное».** Чип как основу не делаем. Только QR, честно: на 100%
  от фото не защитить. Предложено (ждёт ответа): отмечаться только **камерой нашего приложения** (не из галереи), кадр
  скана сохраняется — в нём видна стена/полка вокруг наклейки; при установке точки снимаем «эталон», ИИ сверяет фон
  и замечает экран или бумагу на столе; на улице — GPS; скорость (10 точек за 30 с) — тревога; иногда случайная
  просьба «сними место сейчас». Чип/маячок — только как платный вариант для самых строгих, если попросят.
- **Решение владельца (05.10.2026): защиту от обмана полностью откладываем — для начала хватит простого чек-ина**
  (скан → отметка «кто, когда, где»). Варианты защиты выше — только на будущее.
- **Решение владельца (05.10.2026): чек-ин целиком — «глубокая логика, на этой стадии не нужна».** Не делаем и не
  предлагаем, пока владелец сам не вернётся к теме. Начало: красивые коды, память под кодом, кто видит.
- Владелец места видит табло: кто сегодня был, кто опоздал, какие точки не обошли; выгрузка в Excel.
- Конкуренты есть (приложения учёта времени, системы обхода охраны, билеты на события) — наше отличие: та же
  платформа и красивые фирменные коды; бизнес платит за людей и точки.
- Связь с BookTime: чек-ин клиента в салоне по коду — можно позже.

## Метки-памятки — «инструкция на месте» (04.10.2026)

Пример владельца: сложное отопление (котёл) — каждый раз забывает, как включать, и ищет фото или видео. Решение: код на
котле → скан → шаги, фото, короткое видео, голос. Владелец кода может «Изменить» прямо со скана.
- Кто видит: «только я» / «я и семья» / «все, кто сканирует» (котёл — закрыто, Wi-Fi для гостей — открыто).
- Напоминания («каждую осень проверить давление»), отметка «сделано», история записей (мастер тоже может записать).
- Наклейки, стойкие к жаре и влаге, наборами 10 / 30 / 100.
- Кому ещё: хозяева квартир посуточно (Airbnb — гость сканирует инструкции, хозяину не звонят), офисы и мастерские
  (оборудование и обслуживание), кафе (кофемашина, график мойки), сады и фермы, школы, спортзалы.
- Это ежедневная польза и повторные покупки — хорошая основа бренда; красивые и коллекционные коды — сверху.

## Код с памятью — веб-версия (05.10.2026)

- **В коде — наша ссылка** `/c/<id>` (id случайный, 8 букв/цифр, без порядка). Память и доступ меняются когда угодно —
  код печатать заново не нужно.
- **Мои коды** (`/codes`): свои коды и «Мне открыли». Новый код — сразу «Только я».
- **Настройки кода** (`/codes/<id>`, только хозяин): «Память» (текст, фото до 1600 px, видео до 50 МБ, подпись;
  изменить/удалить), «Кто видит» (Все / Выбранные люди / Только я; люди с правом «Смотреть» или «Смотреть и
  дописывать» и датой «до»; просьбы о доступе — Открыть/Отклонить; ссылка-приглашение + «новая ссылка»; история
  «кто открывал»), «Вид кода» (тот же конструктор, что в генераторе, проверка чтения, скачивание; сохраняется сам).
- **После скана** (`/c/<id>`): память, если открыто; иначе «Код закрыт» → войти / «Попросить доступ»; по
  приглашению — «Принять». Хозяин видит «Настроить», с правом «дописывать» — форму добавления. Внизу «Сделать свой код».
- **Демо-вход** (`/login`): Арман (хозяин кодов), Ани (дописывает в «Котёл»), Давид (смотрит «Котёл»), Лилит (просит
  доступ). Настоящий вход (телефон/почта) — потом.
- **Данные** — в `.data/` (db.json + media, не в git), демо заполняется само; удалить папку = начать заново. Ссылка в
  коде с localhost подменяется на адрес компьютера в сети, `allowedDevOrigins` пускает телефон к дев-серверу.
  Для выкладки нужна настоящая база и хранилище файлов.
- Фото и видео отдаются только тем, кому открыт код; видео — по кусочкам (иначе iPhone не играет).
- Не сделано: оплата, «бесплатно 1 код», приложение, «мои контакты», шаблоны (машина, ключи, питомец); имя хозяина
  на открытых кодах пока видно (для «верните находку» надо скрывать).

### Что ломает QR (проверено — не повторять)

- Проверка: ZXing на двух картинках — чёткой 720 px и «как с камеры» (360 px + размытие 1,2 px). Обе должны прочитаться.
- **Центр каждой клетки** должен остаться тёмным/светлым: дырка в центре точки ломает код («Микросхема» v1).
- **Углы**: нужны сплошная рамка, светлый просвет и тёмный центр. Ломают: светлый центр со значком (пример с Хабра не
  читается), отдельные фигуры без основы (поэтому у «как точки» — тонкая сплошная основа), ножки чипа на средней линии,
  светлые насечки/цветок (поэтому — полутон и тиснение).
- **4-й угол** — нельзя: закрывает служебную разметку; **углы в ряд** — нельзя по устройству QR. Можно — поворот.
- Тиснение значка в углах — до 0,24 (выше ломается); сочетание «рамка как точки + центр звезда» не читается (сайт предупреждает).
- Фото-режим: центры служебных клеток — точки ≥ 0,7; рамку вокруг кода прикрывать дымкой 0,82.
- Светлый код на тёмном фоне читают не все телефоны — поэтому «Космос» — светлая туманность.
